Important terms

- @app.route("/") defines the homepage URL.

- return sends a response to the browser.

- app.run() starts the development server.


Use debug mode only during local development.


Routes
A route is an address on your website that performs a particular task.
Let's add more routes to app.py.

exmaple:

from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Welcome to Pearl's Website!"

@app.route("/about")
def about():
    return "I am learning Python backend development."

@app.route("/hobbies")
def hobbies():
    return "I enjoy coding, reading and creating websites."

if __name__ == "__main__":
    app.run(debug=True)

What is MySQL?

MySQL is a database management system. It stores information in tables, which have columns and rows.

- Table: A collection of related information.
- Column: A type of information, such as name.
- Row: One complete record about a student.
- Primary key: A value that uniquely identifies each record.
- foreign key: from from tables

Creating a database
Install MySQL Server and MySQL Workbench, or use another MySQL client.
Open a SQL query window and run:

sql code:

CREATE DATABASE school_db;

USE school_db;


CREATE TABLE students (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    age INT,
    subject VARCHAR(100)
);


What does this code mean?
- CREATE DATABASE creates a database.
- USE selects the database.
- CREATE TABLE creates a table.
- AUTO_INCREMENT automatically generates a new ID.
- VARCHAR(100) stores text up to 100 characters.
- NOT NULL means a value must be provided.

Understanding the URLs
- / — Displays all student records.
- /add — Displays the form and processes new student submissions.
- /edit/1 — Opens the edit form for student ID 1.
- /update/1 — Updates student ID 1 after form submission.
- /delete/1 — Deletes student ID 1 after confirmation.


Important: Replace 1 with the actual student ID.

RESTAPI

Traditional Python Flask (Without REST API)

In traditional Flask development, the browser sends a request to Flask, 
Flask processes it, communicates with MySQL, and returns an HTML page.


Traditional Flask

Flask returns HTML pages using render_template(). Forms submit using POST, 
and Flask redirects using redirect()


Flask REST API

Flask returns JSON data. JavaScript, mobile apps or other clients communicate
with the backend using HTTP methods such as GET, POST, PUT and DELETE.


Flask REST API is used when you want different applications to communicate with 
the same backend and database.


Where is Flask REST API used?

1. School Management Systems

2. Banking and Fintech Applications

3. E-commerce Applications

4. Hospital Management Systems  etc.
